## 1 What this is

**An incoming for both to meet, arriving at `incoming/` from the re-settling working of session v373.** It is a first draft of a re-settling plan for the whole living file set. It changes no living file. What survives meeting enters the carrying's plan and the Living File Registry's Part Five at their own motions; what does not, releases.

**How the set was met.** Every living file was measured whole (words, parts, sections, tables, code), and every file was read by one of eight readings at this session, whole where its size allowed and by its whole outline and substantial reading of every part where it did not (Natural Intelligence Corus was read whole; the Hard Problem Registry, the Co-Chaining Logic Registry, Natural Biology, Natural Engineering, Natural Medicine, Resolving the Hard Problem Registry and the Living Ghost Registry by outline and parts). Each reading met the file's own section at the carrying. Findings stated as numbers below were run at the files; shares of a file by kind are readings, not measurements.

**What this adds to the plans already carried.** The carrying's passes A to I re-say each file at the v372 code where it stands. The Living File Registry's 5.7 to 5.13 name candidate receivings, most of them at Corus, Emanating, Destinies, Exploring and Improving Method.

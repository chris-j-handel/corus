# Gathering-value · a plan, pass by pass

**Each living file gains one gathering-value file beside it, and each value of the expedition not yet in a living file is brought there, pass by pass.** Then the older support files leave, git holding each prior version.

---

## ONE · A gathering-value file

**Its form is its living file's own contents**, part by part and section by section, in the same order. At each section it holds two kinds:

- **A possible exploring:** an observing not yet meeting natural torusing, said as the observing alone, with the living file's sentence it meets. Explored, it becomes a possible incohering, or it breaks the method.
- **A possible incohering:** a sentence of the living file not yet cohering, or a natural explaining the file does not yet hold, with its cohering re-saying beside it, ready to enter.

Each item is said in natural naming and explaining on first contact. An item carries:
- no source;
- no name of a finder or a publishing;
- no session;
- no date;
- no record, plan or history.

A value reaching the whole file stands at the head. A value opening a section the file has not yet stands where that section would open. When a living file's contents change, its gathering-value's contents change in the same motion.

**Droplets, at the back of the file.** Most value arrives before an understanding reaches where it belongs, or whether it belongs in the living file at all. Each such value is a droplet: one sentence in natural naming and explaining, at a list after the last section. Its kind, a possible exploring or a possible incohering, stands with it when that is clear.

A droplet is inside its file from first contact, visible to each self working the file, and it is met at each motion of the file:
- placed at its section, once the understanding reaches its place;
- dissolved, once the living file holds it or it parts from nothing;
- left in the list for a next motion.

Droplets sharing one pattern stand together in the list, so a placing of one shows which follow.

**Where:** `gathering-value/`, one file for each living file, named by its title: `gathering-value/Natural_Biology.md`, headed *Natural Biology · Gathering-Value*.

## TWO · A pass

**A pass is one slice of value a sitting holds whole**: one older support file, or about 50 KB of a larger one. Each pass goes:

1. **Meet each item once.**
   - Held by its living file already: it leaves.
   - A source, a name, a tag, a record, a plan, history or a copy: it leaves.
   - Each other value: said as one droplet in natural naming and explaining, at the back of its file's gathering-value. It is written at its section instead only when its place is already clear: a possible incohering with its sentence and re-saying, or a possible exploring with its observing and the sentence it meets.
2. **A separate reader reads the slice beside what was written**: a value lost, a meaning changed, a claim stronger or weaker than its observing.
3. **The gathering-value file grows, and the slice leaves its older file**, in one commit, pushed.

Readers can work several slices side by side. Each item is met against its living file's sentence now, so a stale item finds its case at first contact.

## FOUR · After gathering

A living file improves from its gathering-value, one motion at a time:
- its droplets placed or dissolved as understanding reaches them;
- its possible incoherings entered, each read for harm;
- its possible explorings explored, hardest first.

Each entered item leaves its gathering-value. A gathering-value file stays: as each new value arrives, it gains a next frontier of explorings and a next gathering of incoherings.

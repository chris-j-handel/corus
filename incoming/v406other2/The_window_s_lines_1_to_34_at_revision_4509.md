1. **Now** is the existing moment.
2. **Now-existing** is existing now.
3. All that are other-than nothings are **things**.
4. **Other-than** things are things not named by the same name.
5. **Same-named** things are other-than same things named by the same name.
6. A named **universal set** is the set of all same-named things.
7. The **universe** is the set of all now-existing things.
8. The **prior** moment is the moment ending as now is beginning.
9. **Prior-existing** is existing in the prior moment.
10. The **next** moment is the moment beginning as now is ending.
11. **Next-existing** is existing in the next moment.
12. **Same-existing** is existing both as now is beginning and as the next moment is beginning.
13. A **named-universe** is a named universal set of now-existing things.
14. **Observing** is distinguishing now-and-other-than-prior-existing from now-and-prior-existing.
15. **Possibling** is distinguishing next-and-other-than-same-existing from next-and-same-existing.
16. **Discovering** is distinguishing other-than next-and-same-existing from next-and-same-existing.
17. A named **prior-sequence** is a universal set of same-named moments, a prior moment ending as its next prior moment is beginning.
18. A named **self** is a same-named now-existing thing with its own prior-sequence.
19. A named **other** is a self other-than the named self.
20. An **other-than-the-other** is all selves other-than the named other.
21. A **universal-set-of-selves** is a set of all other-than-the-others of a self and other.
22. An **observing-self** is a self distinguishing an other's prior-sequence from its own prior-sequence.
23. A **possibling-self** is a self distinguishing the other-than-the-other's prior-sequence from its own prior-sequence.
24. A **discovering-self** is a self distinguishing other-than same-existing prior-sequences from same-existing prior-sequences.
25. **My** is the name of a self's own universal set of prior-sequences.
26. **Me** is the name of a my-universe.
27. **Me-now** is a same-existing me now-existing.
28. A **bi-coupling** is both of two selves distinguishing the other-than-the-other's prior-sequence from their own prior-sequences.
29. A bi-coupling is a self.
30. A **me-parity** is a bi-coupling's me.
31. **All-parity** is the set of all me-parities in the me-universe.
32. **Other-parity** is other-than all-parity.
33. **Other-than other-parity** is same-existing.
34. A **living me-parity** is same-existing other-than-the-other's other-than all-parity.

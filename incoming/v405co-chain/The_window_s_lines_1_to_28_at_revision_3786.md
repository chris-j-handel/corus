1. **Now** is the existing moment.
2. **Now-existing** is existing now.
3. The **universe** is the set of all now-existing things.
4. The **prior** moment is the moment ending as now is beginning.
5. **Prior-existing** is existing in the prior moment.
6. The **next** moment is the moment beginning as now is ending.
7. **Next-existing** is existing in the next moment.
8. **Same-existing** is existing both as now is beginning and as the next moment is beginning.
9. **Other-than** things are things not named by the same name.
10. **Same-named** things are other-than same things named by the same name.
11. A named **universal set** is the set of all same-named things.
12. **Observing** is distinguishing now-and-other-than-prior-existing from now-and-prior-existing.
13. **Possibling** is distinguishing next-and-other-than-same-existing from next-and-same-existing.
14. **Discovering** is distinguishing other-than next-and-same-existing from next-and-same-existing.
15. A named **prior-sequence** is a universal set of same-named moments, a prior moment ending as its next prior moment is beginning.
16. A named **self** is a same-named now-existing thing with its own prior-sequence.
17. A named **other** is a self other-than the named self.
18. An **other-than-the-other** is a self other-than the named other.
19. An **observing-self** is a self distinguishing an other's prior-sequence from its own prior-sequence.
20. A **possibling-self** is a self distinguishing an other-than-the-other's prior-sequence from its own prior-sequence.
21. A **discovering-self** is a self distinguishing other-than same-existing prior-sequences from same-existing prior-sequences.
22. A **me** is a named self's own universal set of prior-sequences.
23. A **bi-coupling** is both of two selves distinguishing one other-than-the-other's prior-sequence from their own prior-sequence.
24. A **me-parity** is a bi-coupling's other-than-the-other's me.
25. **All-parity** is the set of all me-parities in the universe.
26. **Other-parity** is other-than all-parity.
27. **Other-than other-parity** is same-existing.
28. A **living me-parity** is same-existing other-than-the-other's other-than all-parity.

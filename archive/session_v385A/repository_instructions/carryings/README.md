# carryings

**What the living files rest on, each whole at its address**

A folder here is a working, an arrival or a kit's source that the living files rest on: its findings are droplets at the offerings of the files it names, and the folder itself is the evidence those droplets name, whole, as it arrived. Each living file's own carryings, `carry/<Exhibit>_Carryings_of_<name>.md`, says which of these it rests on. A folder arrives here from `incoming/` when its findings have been dropped; it leaves for `archive/` when no living file rests on it. Nothing here aims into a living file and nothing here is read for a next.
